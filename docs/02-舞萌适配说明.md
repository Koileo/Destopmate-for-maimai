# 舞萌适配说明

目标环境：Windows x64、SDEZ 1.70 / Sinmai、Unity 2018.4.7f1、MelonLoader 0.6.4。运行时通过反射挂接游戏，不在编译时引用 Assembly-CSharp。其他版本若缺少状态或触摸接口，会记录日志并降级。

## 布局

按实际窗口尺寸和玩家区域计算位置；`ReferenceWidth/Height` 仅用于画布缩放，不要求游戏窗口采用该分辨率。

竖屏按 1080:1920 内容比例适配，下方主圆区域宽度为 `min(玩家区域宽度, 高度×1080/1920)`。`CircleCenterY=-1` 自动定位主圆，其他值按玩家区域高度比例解释。`CircleRadius` 是主圆区域宽度的比例，默认 0.5。

默认 `CircleEntrance=true`、`AnimatedEntrance=false`：大比例靠右淡入，`CircleResidentY=-1.12` 把脚放到圆形边界下方，腿沿圆周自然遮挡，避免悬空露脚。CircleHeightRadius 控制人物图高度 / 半径上限，仍受 HeightPixels 与 Scale 限制；CircleResidentX/Y 控制人物图中心 X、底边 Y 相对圆心的偏移 / 半径，Y 支持 -1.8~0。固定站位不把含透明边距的整张人物图压进窄侧栏。较大的角色可能覆盖右侧部分提示，可用位置字段微调。

本地角色站姿在采样后补偿较低支撑脚的高度与双脚中心漂移；坐姿不施加站立补偿。这不是完整双脚 IK，仍保留腿部关节和上身动作。每帧在原点计算骨骼并完成离屏渲染，随后恢复远处隔离位置，避免两万单位坐标的浮点精度造成抖动，也避免角色进入游戏相机画面。

上屏陪伴仅用于同一竖屏画面上方的矩形区域，不是 Windows 第二显示器。角色整图限制在玩家区域右侧 45%~97% 之间，以臀部对齐坐垫。`UpperSeatX/Y` 调整坐垫位置；`UpperSeatHeight` 控制相对主圆区域宽度的高度，最终受上屏边界限制。

横向输出宽高比大于 2.4 时，画面按 1P/2P 分半。`Auto`、`1P`、`Both` 均显示一个左侧角色；`2P` 显示一个右侧角色。当前不复制双角色。

`CircleEntrance=false` 时，`Anchor/OffsetX/OffsetY/Scale/HeightPixels` 控制角落位置；此自定义模式不保证中央避让。`AnimatedEntrance=true` 保留旧版探头/绕圆路径，默认关闭。

## 状态与输入

角色默认离屏渲染为 1620×1620、4× MSAA，贴图使用三线性过滤；仅影响角色渲染台，不更改 QualitySettings。RenderTextureWidth/Height 与 RenderTextureAntiAliasing 可降低显存和填充率开销；不支持多重采样的显卡使用单采样。

原版动作采样使用连续插值，循环尾部与下一轮的移动片段交叠，循环后接续该片段时间，避免先收回到第零帧又突然起步。v0.5.4 的 StandingIdleMotion 默认 0，休息时保持固定站姿；原版与程序动作回退均停止连续呼吸、重心和噪声摆动。主动思考、叉腰等动作与坐姿保留。返回站姿后先完成混合并精确收敛，再停止重复写入骨骼与支撑修正，避免残余小幅抖动。眼神固定朝前，原版动作中的眼球肌肉也保持中立；独立微笑与眨眼不受影响。

`ProcessManager` 的进程通知控制显示，Entry 的 `DoneEntry` 标记本轮登录。选曲、模式、票券、角色和课程选择页面允许上屏坐姿；读取、未知页面、游玩及结算不展示上屏陪伴。F8 或 `UpperSeatOnLogin=true` 选择上屏，回招揽时清除本轮选择。换位时先淡出，再移动，最后淡入。

整个 Entry 刷卡流程禁止下屏展示，包括尚未识别子界面、等待刷卡、读卡与登录完成；旧配置 `ShowInEntryWaiting=true` 和 `ForceShow` 均不能覆盖。进入 Entry 后不等待隐藏缓冲，直接在当前站位淡出。

默认 `HideDuringGame=true` 优先于调试强制显示，游玩/结算开始也直接淡出，完全隐藏后停止动画。淡出不倒放进场或重置姿势；连续可展示页面不重复等待 ShowDelaySeconds，短暂进程空档保留隐藏缓冲。触摸反馈无论该开关如何设置，在游玩/结算都不触发。

触摸通过 `Manager.InputManager.UpdateTouchPanel` 的 Harmony 后置补丁读取 `GetTouchPanelAreaAnyDown(int player)`。只读取已有游戏状态，不改变返回值、触摸数组、按键或判定。每帧合并事件，按玩家区域筛选，隐藏时立即丢弃，避免恢复显示后补播。

`Interaction.TouchEnabled=true` 开启互动，`TouchCooldownSeconds` 默认 8 秒，读取配置时限制为 2~60 秒。站姿选择角色支持的短动作；原版初音使用换重心。坐姿或 `ReducedMotion=true` 时只微笑，1.2 秒后恢复默认表情；站姿片段沿用原动作时长和驱动混合。当前不提供触摸区域对应身体部位的映射。

覆盖画布没有 `GraphicRaycaster`，`CanvasGroup.blocksRaycasts=false`；没有消息框、屏幕按钮及其他可交互 UI。触摸游戏原有按钮仍可能推进游戏界面，互动会随显示状态结束。

## 常用配置

| 需求 | 字段 |
| --- | --- |
| 换角色 | `Display.Renderer`、`Character.Id` |
| 改下屏大小上限 | `Display.CircleHeightRadius`、`Display.Scale`、`Character.HeightPixels` |
| 改下屏固定站位 | `Display.CircleResidentX/Y`，相对圆心、以半径为单位 |
| 改上屏位置 / 大小 | `Display.UpperSeatX/Y/Height`，受上屏边界限制 |
| 无键盘自动上屏 | `Display.UpperSeatOnLogin=true` |
| 禁止上屏 | `Display.AllowUpperSeat=false` |
| 关闭触摸互动 | `Interaction.TouchEnabled=false` |
| 减少额外动作 | `Animation.ReducedMotion=true` |
| 待机动作池与节奏 | `Animation.IdleVariants/IdleWeights/IdleMinSeconds/IdleMaxSeconds` |
| 调整层级 | `Display.SortingOrder`；若覆盖 AquaMai 菜单则降低 |
| 检查资源 / 布局 | `Debug.ForceShow`、`Debug.CaptureOnShow` |

完整字段见 `assets/DesktopMate.toml`。配置重启生效，安装脚本保留已有文件。
