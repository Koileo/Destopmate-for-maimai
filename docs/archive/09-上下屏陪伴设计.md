# 上下屏陪伴设计

未登录时，角色完整地待在下方圆屏；登录后由玩家选择上屏陪伴。下屏采用已有的整图圆形布局，不恢复头身分离或默认绕圆路径。上屏采用右侧小比例坐姿和薄荷色椭圆坐垫，中心区域留给游戏内容。

## 选择与位置

登录完成后，选曲、模式选择、角色选择、票券选择和课程选择页面提供「♡ 让她坐到上屏」鼠标按钮，也可用 F8 切换；再次选择可收起。页面外不显示按钮。没有上屏的横屏布局、没有坐姿的角色不显示此选项。机台触摸和游戏按键仍交给游戏，不映射为 Mod 操作。

```toml
[General]
HotkeySeat = "F8"

[Display]
AllowUpperSeat = true
UpperSeatOnLogin = false
UpperSeatX = 0.78
UpperSeatY = 0.48
UpperSeatHeight = 0.42

[Animation]
EnableActionCombos = true
ReducedMotion = false
```

合并到已有同名栏目。`UpperSeatOnLogin=true` 适合没有鼠标、键盘的机台：每轮登录后自动选择上屏。默认 false，登录后先收起，由用户主动选择。选择只在本轮会话保留，游玩结束回选曲后恢复，回招揽页后清除。

X 是玩家区域宽度比例，Y 是上方矩形区域内自底向上的比例；Height 是人物渲染图相对主屏宽度的高度。布局限制整张人物图在上屏内，并以相机投影的臀部坐标贴合坐垫。角色从下屏到上屏、注销回下屏都先在原处淡出，再改变位置和姿态，最后淡入；途中再次选择会改变目标。

上屏使用的是同一竖屏画面中的矩形显示区域，不是 Windows 的第二显示器。横向 1P/2P 拼接时，Auto 选择左侧玩家区域，2P 可指定右侧；单角色不会横跨两个玩家屏幕。

## 动作与表情

本机初音在已有站姿池中编排三种短组合：思考→换重心、叉腰→思考、换重心→叉腰。保留 Idle 权重和大动作间的停顿，等待当前片段完成后再续下一段。仅使用 `IdleVariants` 中具有正权重、角色实际支持的动作，单一 Idle 配置不会被改成动作组合。

支持相应动作的其他角色还可使用招手→点头、张望→点头。原版初音没有导入招手片段，不将其他片段冒充招手。

偶尔出现「让我想想～」「我就在这里陪你」等短气泡，停留三秒、仅淡入淡出，至少间隔八秒；不随视线漂移。坐姿期间不启动站立手势。`ReducedMotion=true` 取消额外手势组合、视线跳动和旧版空间进场，保留角色原有自然循环和眨眼。

## 坐姿资源

本机离线动作文件增加原版 `b1` 坐姿。`tools/export_local_motion.py` 默认导出 a1/a2/a4/a8/b1，角色和动作仍只保存在本机。没有 `motion.dmm` 或没有 b1 的本地角色不提供坐姿；2D 角色可提供 `sprites/sit_*.png`。旧文件仍可读，原来的站姿不受影响。资源更新后重启游戏。

## 验证范围

行为检查覆盖登录状态跨页面保留、登录瞬间选择、透明时换位、连选、游玩隐藏、回选曲恢复、注销回下屏，以及缺少坐姿/上屏时的降级。动作检查覆盖组合顺序、忙碌等待、坐姿不抢站立动作和减少动态选项。运行：

```powershell
& .tools/dotnet/dotnet.exe run --project tests/BehaviorChecks/BehaviorChecks.csproj -c Release
& .tools/dotnet/dotnet.exe run --project tests/MotionChecks/MotionChecks.csproj -c Release
```

登录检测沿用 Entry 的 DoneEntry 信号，通过明确的选曲页面白名单启用上屏；读取中、未知页面、游玩和结算不展示上屏角色。真实刷卡、各页面实际信息遮挡、不同角色与双玩家机台仍需现场确认。
