# 角色资源与开发

## 项目结构

- `src/Config`：配置与简化 TOML 读取。
- `src/Core`：机台状态、只读触摸、布局、角色加载、显示与待机。
- `src/Core/Motion`：程序动作、Humanoid 重放、骨骼与表情绑定。
- `assets`：默认配置、2D 测试图；`assets/local` 是不提交源码的本机转换角色，发版时从中收录默认 Miku。
- `tests`：无界面状态、动作与转换检查。
- `tools`：离线角色转换、动作导出、发布打包。
- `docs/archive`：早期结构研究、设计与验收记录，保留供追溯。

构建使用 `net472` / C# 7.3。运行时只依赖游戏已有 Unity、MelonLoader 和 Harmony，不修改 AquaMai、游戏判定、输入或全局渲染设置。

## 本地 Desktop Mate 转换

原始 `.cb` 以及 Unity 6 AssetBundle 不能直接交给 Unity 2018.4。转换器将网格、骨骼、蒙皮、表情和主贴图导出为 `character.dmc` 与 PNG，由 `PortableCharacter` 重建。

需要 Python 3.12，以及 `tools/requirements.txt` 中的依赖。工具会优先读取 `.tools/python`。从 [DesktopMateAssetDecryptor](https://github.com/Xyzstk/DesktopMateAssetDecryptor) 取得所需 `keys.bin` 并放在 `.tools/asset-converter/keys.bin`；文件不在本仓库中。

在项目根目录运行：

```powershell
python -m pip install -r tools/requirements.txt --target .tools/python
python tools/read_character_bundle.py "C:\path\to\miku.cb" .tools/miku.unity3d --decode-only
python tools/export_local_character.py .tools/miku.unity3d "C:\path\to\miku.cb" assets/local/miku-local
python tools/validate_portable_character.py assets/local/miku-local/character.dmc
python tools/export_local_motion.py .tools/miku.unity3d assets/local/miku-local/motion.dmm
```

初音动作默认导出 a1/a2/a4/a8/b1，分别用于自然站立、思考、换重心、叉腰和坐姿。动作通过 Unity Humanoid 重定向，不导入根位移与根转向，片段切换沿用 0.25 秒混合。未带 `motion.dmm` 的角色回退到程序动作。

批量转换并安装：

```powershell
python tools/convert_all_characters.py "<Desktop Mate目录>\DesktopMate_Data\StreamingAssets\AssetBundle" --install "<Package>\Mods\DesktopMate\Characters"
```

结果保存在 `assets/local/<角色包名小写>-local`；检查报告与角色列表分别为 `conversion-report.json`、`CHARACTERS.md`。其他角色的骨骼命名、表情及动作需要单独验收。

## 自制资源

3D AssetBundle 使用 Unity 2018.4.7f1、Windows x64、内置渲染管线导出，文件名为 `character.ab`。可在编辑器使用 UniVRM 0.63.x 导入 VRM 0.x，配置 Animator 的 Idle / Wave / Nod 等 Trigger 与状态；角色没有相应动作时不会强制播放。

2D 使用透明 PNG、统一画布尺寸，按 `sprites/idle_0.png`、`idle_1.png` 等命名；可添加 `wave_*.png`、`nod_*.png`、`shift_*.png`、`sit_*.png`。缺少 Sit 的角色不提供上屏坐姿。

## 检查与打包

```powershell
dotnet run --project tests/BehaviorChecks -c Release
dotnet run --project tests/MotionChecks -c Release
python -m unittest discover -s tests -p "test_*.py"
powershell -File tools/package_release.ps1
```

无界面 C# 检查复用生产源码，替换 Unity / 显示边界。打包前先构建 Release，并准备 `assets/local/miku-local` 下的 `character.dmc`、配套 PNG 与 `motion.dmm`；缺少模型、动作或引用贴图时打包会失败，不会回退到占位图。可通过 `-MikuSource <目录>` 指定另一份 Miku 导出目录。

v0.5.3 起发布包收录 DLL、默认配置、默认 Miku 的模型/贴图/动作、安装与第三方说明。不会收录 `source.json` 中的本地路径、其他角色、原始 `.cb` 或解密数据。
