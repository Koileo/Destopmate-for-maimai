# 安装与验证

目标环境：Windows x64、SDEZ 1.70 / Unity 2018.4.7f1、MelonLoader 0.6.4。已与本机 AquaMai 1.9.7 一同启动。

## 安装发布包

退出游戏，将压缩包内 `Mods` 合并到游戏 `Package/Mods`。已有配置请先备份，按需合并新增字段。发布包只附带简易 2D 测试图，默认 `Renderer="2D"`、`Id="placeholder"`。

正式人物需自行准备。3D 支持 `Characters/<Id>/character.dmc` 配套 PNG，或 Unity 2018.4.7f1 导出的 `character.ab`。2D 支持 `Characters/<Id>/sprites/idle_0.png` 等透明序列帧。原始 Desktop Mate `.cb` 不能直接放进此运行时；本地数据转换方法见源码仓库 README。

本机初音已安装在 `Characters/miku-local`，选择 `Renderer="3D"`、`Id="miku-local"`、`YawDegrees=180`。该角色素材不包含在发布包中。

## 检查显示

启动后检查 `MelonLoader/Latest.log` 是否有“机台状态监听已安装”和“角色已就绪”。进入招揽/等待刷卡界面后，默认闲置 15 秒出现。此开发机器的配置使用 18 秒，让标题动画先完成。

`CircleEntrance=true` 时从圆外探头，停顿 1.3 秒，再在 1.2 秒内露出身体、进入圆内。`CircleCenterY=-1` 自动适配竖屏主圆；其他窗口请调整圆心和半径。原始 Desktop Mate 光照、完整动作和头发物理尚未移植。

`F9` 开关显示。`Debug.ForceShow=true` 可检查加载和位置；默认 `HideDuringGame=true`，游玩/结算仍然立即隐藏。

`Debug.CaptureOnShow=true` 保存首次探头、进入、站立三阶段截图及 3D 人物 RT 图到 `Mods/DesktopMate`。验收后关闭此选项。
