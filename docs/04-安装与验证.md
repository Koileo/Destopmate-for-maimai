# 安装与验证

适用环境：Windows x64、SDEZ 1.70 / Unity 2018.4.7f1、MelonLoader 0.6.4。

## 安装

退出游戏，将发布 ZIP 内的 `Mods` 合并到游戏 `Package/Mods`。已有配置先备份，合并新字段。v0.5.3 起发布包包含 Mod、默认配置和 Miku 的模型、贴图与动作，不包含游戏 DLL、其他角色、原始 `.cb` 或解密数据。

配置位置为 `Mods/DesktopMate/DesktopMate.toml`，修改后重启生效。默认 `Renderer="3D"`、`Character.Id="miku-local"`、`YawDegrees=180`。其他角色放在 `Mods/DesktopMate/Characters/<id>`，支持本地转换的 `character.dmc` 配套 PNG / `motion.dmm`、Unity 2018.4.7f1 导出的 `character.ab`，或 `sprites/idle_0.png` 等透明序列帧。

Miku 资源无需另行转换即可使用。源码构建时的转换方法见仓库 `docs/开发与角色转换.md`。旧配置可以保留；刷卡隐藏规则同样生效，若仍指向占位图则同步上述三个默认角色字段。

## 升级位置与互动配置

将以下字段合并到已有同名栏目，勿重复添加栏目。v0.5.2 保留大比例，将下屏站位下移至腿自然沿圆边遮挡；安装脚本保留已有配置，升级时需同步 CircleResidentY。

```toml
[Display]
RenderTextureWidth = 1620
RenderTextureHeight = 1620
RenderTextureAntiAliasing = 4
CircleEntrance = true
AnimatedEntrance = false
CircleHeightRadius = 1.65
CircleResidentX = 0.46
CircleResidentY = -1.12
UpperSeatX = 0.78
UpperSeatY = 0.48
UpperSeatHeight = 0.52
UpperSeatOnLogin = false

[Interaction]
TouchEnabled = true
TouchCooldownSeconds = 8

[Animation]
StandingIdleMotion = 0
IdleVariants = ["Idle", "Think", "HandsOnHips", "Shift", "LookAround", "Nod", "Wave"]
IdleWeights = [7, 2, 1, 1, 1, 1, 1]
```

## 实机检查

1. 查看 `MelonLoader/Latest.log` 中的“机台状态监听已安装”“触摸互动已接入”“角色已就绪”。接口不匹配时会有降级日志。
2. 标题 / 招揽界面首次默认 15 秒后显示；切换至另一个可展示页面不应反复消失再出现。确认角色大比例靠右、脚藏在圆边下方、腿沿圆周裁切；连续观察待机、换重心与动作循环，检查身体没有上下跳动或整体漂移，并检查页面提示遮挡。进入刷卡界面应立即开始原地淡出，等待超过 15 秒也不重新出现；读卡、登录子页面切换不闪现。没有消息框或屏幕按钮。
3. 触摸圆屏：空闲站姿应播放支持的点头 / 挥手 / 换重心 / 思考之一并微笑。默认 8 秒内连续触摸不会重复触发；正在播放动作时不会打断。触摸也会继续交给游戏。
4. 登录后选曲时按 F8 上屏，再按 F8 收起；无键盘可设置 `UpperSeatOnLogin=true`。需要竖屏上方区域及真实坐姿。确认角色在上屏右侧，触摸时只微笑、不站起来。
5. 游玩和结算时确认角色立即开始淡出，完全隐藏后停止动作。回选曲恢复本轮上屏选择，回招揽恢复下屏站姿；隐藏期间的触摸不会补播。短暂反向切换时透明度连续，不能重置到 0 或 1。
6. 2P 设置 `PlayerSlot="2P"`，确认只有 2P 触摸触发。开启 `ReducedMotion=true` 后只提供微笑回应。
7. 在大屏观察头发、衣摆与腿部斜边：默认 1620×1620、4× MSAA，应比旧版 1080×1080 无抗锯齿更平滑。连续观察至少 30 秒，休息时身体应固定，不持续摇摆或上下抖动；保留眨眼与微笑，眼神不再四处移动。思考/叉腰等主动动作结束后应平滑回到固定站姿。显存或帧率紧张时降低角色分辨率与采样数。

F9 开关角色。`ForceShow=true` 可用于定位，刷卡流程和默认游玩/结算隐藏仍优先。`CaptureOnShow=true` 可保存截图到 `Mods/DesktopMate`；验证后关闭。旧截图文件名含 peek/enter，仅表示采样时刻，默认已不播放旧进场。
